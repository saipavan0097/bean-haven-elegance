# Bean Haven Elegance

Build a premium, modern, luxury coffee shop website called "Bean Haven".

Goal:

Create an agency-quality website that looks like it was designed by an experienced UI/UX designer. The website must be fully responsive for desktop, tablet, and mobile.

Style:

- Premium, elegant and luxurious

- Warm coffee color palette (dark brown, cream, beige, gold accents)

- Glassmorphism where appropriate

- Smooth modern animations

- Soft shadows

- Rounded corners

- High-quality typography

- Clean spacing

- Professional UI

- Premium user experience

- Fast loading
